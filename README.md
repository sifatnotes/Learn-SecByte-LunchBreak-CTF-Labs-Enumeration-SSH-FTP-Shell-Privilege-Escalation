## Learning Path

A suggested learning sequence:

1. Start with **LunchBreak Enumeration** to build reconnaissance and enumeration skills.
2. Continue with **Lunchbreaker Home Hunt** and **LunchBreak Shell Hunt**.
3. Explore **FTP User Trail** and **Lunchbreaker SSH Crack**.
4. Study **Wordlist Whisperers** for wordlist-related techniques.
5. Practice **Switcheroo – SU Basics** to understand SU fundamentals.
6. Continue through **Lunchbreaker Loot Trail** and **LunchBreak Loot**.
7. Finish with the root-focused challenges: **Breadcrumbs to Root**, **LunchBreak to Root**, and **Lunchbreak Root Sprint**.

Adapt the sequence according to your current experience.

## How to Use the Labs

1. Select a challenge from the index.

3. Review the objectives, prerequisites, and rules.

7. Move to related labs as your skills develop.
